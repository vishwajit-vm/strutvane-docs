Durable multi-step workflows with human approvals and timers.

Laravel has no first-party equivalent. Phase 7.

Once it is released, you add it to an existing app with one command:

```bash
node strut install:workflows
```

The installer adds the package with npm, writes `config/workflows.ts`, adds any `.env` keys, copies its migrations into `database/migrations/` and registers its provider in `bootstrap/providers.ts`.
