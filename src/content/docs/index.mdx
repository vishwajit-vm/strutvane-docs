## Strutvane in one paragraph

Building a business app usually means writing the same things again and again: database tables, an API to read and save data, a login system, "who is allowed to do what", and screens with tables and forms. **Strutvane does that repetitive work for you.** You describe your data, such as "an invoice has a number, an amount and a status", and Strutvane creates everything around it. The result is ordinary TypeScript code in your own project, so you can read it, change it, and keep it forever.

## A tiny example

<Tabs>
  <TabItem label="What you write">

```ts title="app/models/invoice.model.ts"
import { defineModel, field } from '@strutvane/framework'

export default defineModel('Invoice', {
  number: field.string().unique(),
  amount: field.decimal(12, 2),
  status: field.enum(['draft', 'sent', 'paid']).default('draft'),
})
```

  </TabItem>
  <TabItem label="What you get">

```text
✔ A database table called "invoices", created by a migration
✔ API:  GET /api/v1/invoices    (list, search, filter, sort, paginate)
        POST /api/v1/invoices   (create, with validation)
        PATCH /api/v1/invoices/:id · DELETE /api/v1/invoices/:id
✔ Permissions: invoice.view, invoice.create, invoice.update, invoice.delete
✔ Screens: /invoices (table), /invoices/new (form), /invoices/:id (details)
✔ Interactive API docs at /docs
```

  </TabItem>
</Tabs>

That's the whole idea: **declare the model, ship the app.**
