## What it is

The devkit is for people who **extend Strutvane**: plugin authors, companies building internal presets, and the Strutvane team itself. Every official package uses it.

## Installers: how `pnpm sv add <package>` works

When you run `pnpm sv add auth`, the auth package's **installer** runs. It:

- adds the right dependencies
- writes the config file
- adds settings to `.env` **and** `.env.example`
- creates database migrations
- registers itself in `strutvane.config.ts`

The devkit makes installers **safe**:

| Safety feature | What it means for you |
|---|---|
| Preview | `--dry-run --diff` shows every change before it happens |
| All-or-nothing | If anything fails halfway, no files are changed |
| Run twice, no harm | Running an installer again just repairs anything missing |
| Undo | `pnpm sv remove <package>` reverses it and keeps any files you edited |

## Example: an installer for a "notify" plugin

```ts title="installer.ts"
import { defineInstaller } from '@strutvane/devkit'

export default defineInstaller({
  name: 'notify',
  async install({ deps, fs, env, config }) {
    await deps.add({ '@acme/strutvane-notify': '^1' })
    await fs.template('config/notify.ts', templates.config)
    await env.add('Notifications', { NOTIFY_DEFAULT_CHANNEL: 'mail' }) // → .env and .env.example
    await config.registerProvider('@acme/strutvane-notify/provider')
  },
})
```
