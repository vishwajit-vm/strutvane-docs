## What it does

- **Automatic screens** for every model: a table, a form and a detail page ([The UI](../../concepts/the-ui/))
- **Sign-in and admin screens** when auth is installed
- **Permission-aware:** shows only what each user is allowed to do
- **Owned components:** buttons, tables and inputs are copied into your project for you to change
- **Theming:** colours, fonts and dark mode from one file
- **Accessible:** designed for keyboard and screen-reader users
- Built with React, Vite, TanStack and Tailwind CSS: popular, well-documented tools

## Install (planned)

```bash
# add screens to an existing Strutvane project
pnpm sv add ui

# or create a UI-only project for an API you already have
npm create strutvane@latest my-admin -- --preset ui
```

## Example: UI-only mode for an existing API

Already have an API? If it publishes an **OpenAPI** description (a standard file describing its endpoints), the UI can build screens from it:

```dotenv title=".env"
VITE_API_URL=https://api.example.com
API_OPENAPI_URL=https://api.example.com/openapi.json
```

If the guesses need adjusting, tell it more in one file:

```ts title="ui.resources.ts"
export default {
  orders: { label: 'Orders', titleField: 'reference', list: { columns: ['reference', 'customer', 'total'] } },
}
```

## Customising

The UI follows the same [levels of control](../../concepts/levels-of-control/) as the rest of Strutvane: change settings, override one column or widget, or eject a whole page with `pnpm sv eject ui`.
