## How to run commands

Inside a project, use `pnpm sv <command>`. Outside a project, use `npx strutvane <command>`.

Both `make:model` and `make model` work, so use whichever feels natural.

## Flags that work everywhere

| Flag | What it does | Example |
|---|---|---|
| `--dry-run --diff` | Show what would change, without changing anything | `pnpm sv make:model Tag name:string --dry-run --diff` |
| `--yes` | Accept the defaults; don't ask questions | `pnpm sv add auth --yes` |
| `--json` | Machine-readable output, for scripts and CI | `pnpm sv routes --json` |
| `--help` | Explain a command | `pnpm sv migrate --help` |

## Starting and running

| Command | Plain meaning | Example |
|---|---|---|
| `strutvane new` | Create a new project (same as `npm create strutvane`) | `npx strutvane new acme` |
| `sv up` / `sv down` | Start / stop local services (database, cache, mailbox) in Docker | `pnpm sv up` |
| `sv dev` | Run the app with live reload (same as `pnpm dev`) | `pnpm sv dev` |
| `sv build` / `sv start` | Production build / run it | `pnpm sv build && pnpm sv start` |
| `sv doctor` | Check the project for problems and suggest fixes | `pnpm sv doctor` |
| `sv about` | Show versions and settings (handy for bug reports) | `pnpm sv about` |
| `sv upgrade` | Upgrade Strutvane safely, with automatic code fixes | `pnpm sv upgrade` |

## Making things (generators)

| Command | Creates | Example |
|---|---|---|
| `sv make:model` | A model (plus factory, seeder and test with `--all`) | `pnpm sv make:model Invoice number:string amount:decimal(12,2) --all` |
| `sv make:resource` | Extra behaviour for a model: hooks and actions | `pnpm sv make:resource Invoice` |
| `sv make:policy` | Authorization rules for a model | `pnpm sv make:policy Invoice` |
| `sv make:action` | A custom action, like "approve" | `pnpm sv make:action Invoice approve` |
| `sv make:migration` | A hand-written migration | `pnpm sv make:migration backfill_invoice_numbers` |
| `sv make:seeder` / `sv make:factory` | Starting data / fake-data recipes | `pnpm sv make:seeder DemoData` |
| `sv make:job` | A background task | `pnpm sv make:job SendWeeklyReport` |
| `sv make:event` / `sv make:listener` | Something that happens / a reaction to it | `pnpm sv make:listener EmailOnInvoicePaid` |
| `sv make:mail` | An email template | `pnpm sv make:mail InvoiceReminder` |
| `sv make:command` | Your own CLI command | `pnpm sv make:command CleanupOldDrafts` |
| `sv make:test` / `sv make:page` | A test / a custom UI page | `pnpm sv make:page reports/revenue` |

**Field syntax** for `make:model`: `name:type[:modifier...]`, for example:

```bash
pnpm sv make:model Deal title:string:unique "company:belongsTo(Company)" \
  amount:decimal(12,2) "stage:enum(lead,won,lost):default(lead)" closeDate:date:optional
```

<Aside type="tip">
Put quotes around fields that contain brackets or commas, like `"stage:enum(lead,won,lost)"`, so your terminal doesn't misread them.
</Aside>

## Database

| Command | Plain meaning | Example |
|---|---|---|
| `sv migrate` | Bring the database up to date with your models | `pnpm sv migrate` |
| `sv migrate:status` | Which migrations have run | `pnpm sv migrate:status` |
| `sv migrate:rollback` | Undo the last batch | `pnpm sv migrate:rollback` |
| `sv migrate:fresh` | **Dev only:** wipe and rebuild (add `--seed` for fake data) | `pnpm sv migrate:fresh --seed` |
| `sv db:seed` | Fill the database with seed data | `pnpm sv db:seed` |
| `sv db:pull` | Create models from an existing database | `pnpm sv db:pull` |
| `sv db:shell` | Open a database prompt | `pnpm sv db:shell` |

Destructive commands refuse to run in production unless you explicitly force them.

## API

| Command | Plain meaning | Example |
|---|---|---|
| `sv routes` | List every endpoint, its permission and the file it comes from | `pnpm sv routes` |
| `sv models` | List models and their fields | `pnpm sv models` |
| `sv api:docs` | Export the OpenAPI file | `pnpm sv api:docs --out openapi.json` |

## Auth, tenants and audit

| Command | Plain meaning | Example |
|---|---|---|
| `sv auth:user:create` | Create a user | `pnpm sv auth:user:create --email ana@acme.test --role admin` |
| `sv auth:role:create` | Create a role | `pnpm sv auth:role:create accountant` |
| `sv auth:permissions:sync` | Sync model permissions into the database | `pnpm sv auth:permissions:sync --dry-run` |
| `sv auth:matrix` | Print who can do what | `pnpm sv auth:matrix --format md` |
| `sv auth:explain` | Explain why something was allowed or denied | `pnpm sv auth:explain --actor ana@acme.test --action invoice.approve --resource invoice:42` |
| `sv auth:token:create` | Create an API key for a program | `pnpm sv auth:token:create --name billing-sync` |
| `sv auth:sso:add` | Connect a company's single sign-on | `pnpm sv auth:sso:add --tenant acme --type saml --metadata-url https://…` |
| `sv tenant:create` | Create a tenant (customer company) | `pnpm sv tenant:create acme` |
| `sv audit:verify` | Check the audit log hasn't been tampered with | `pnpm sv audit:verify` |
