**What you'll learn**

- What every folder in a Strutvane project is for

<Aside type="caution" title="Planned, not available yet">
This is the planned layout of a project created with `npm create strutvane@latest`.
</Aside>

## The tour

<FileTree>
- app/ **your application code**
  - models/ what your data looks like (start here)
    - invoice.model.ts
  - resources/ optional extra behaviour per model (hooks, actions)
  - policies/ who may do what (authorization rules)
  - services/ your business logic
  - http/
    - routes/api.ts your own custom endpoints
    - middleware/ code that runs on every request
  - jobs/ background tasks (for example, sending a report at night)
  - events/
  - listeners/ reactions to events ("when an invoice is paid, email the customer")
  - mail/ email templates
  - providers/app.provider.ts start-up wiring for your app
- config/ **settings**, readable and typed
  - app.ts
  - database.ts
  - auth.ts
  - …
- database/
  - migrations/ database changes, generated and committed to Git
  - seeders/ fills the database with starting or fake data
  - factories/ recipes for fake records, used in tests
- web/ **the screens** (only if you use the UI)
  - pages/ page overrides (automatic pages need no files)
  - components/ui/ buttons, tables and inputs: yours to change
  - theme/tokens.css colours and fonts
- tests/ feature, unit and end-to-end tests
- storage/ logs and uploads (not committed)
- docker/ local services (local only, not committed)
- .strutvane/ generated by Strutvane (not committed, rebuilt automatically)
- .env your local settings and secrets (**never committed**)
- .env.example every setting, documented (committed)
- strutvane.config.ts which Strutvane packages are switched on
- package.json
</FileTree>

## What you edit vs. what's generated

| You edit | Generated for you (don't edit) |
|---|---|
| `app/**`, `config/**`, `web/pages/**`, `web/components/**` | `.strutvane/**` (rebuilt every time you run `pnpm dev` or `pnpm build`) |
| `database/seeders`, `database/factories` | `database/migrations/*.sql` (generated once, then committed and never changed) |
| `.env` (your machine only), `.env.example` | |

## Where should my code go?

| I want to… | Put it in |
|---|---|
| Add a new kind of data | `app/models/` (use `pnpm sv make:model`) |
| Run code before or after saving a record | `app/resources/<model>.resource.ts` (hooks) |
| Add a button like "Approve" | `app/resources/<model>.resource.ts` (actions) |
| Write business logic used in several places | `app/services/` |
| Add an endpoint that isn't about one model | `app/http/routes/api.ts` |
| Do something slow without making users wait | `app/jobs/` |
| Change how a screen looks | `web/pages/` or `web/components/ui/` |

<Aside type="tip">
Run `pnpm sv routes` at any time to list every endpoint and which file it comes from.
</Aside>
