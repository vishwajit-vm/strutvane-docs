**What you'll learn**

- The four levels of control, and when to use each
- How to customise one small piece without losing the automatic features
- Why you can never get "stuck" with Strutvane

<Aside type="caution" title="Pre-release (0.1.0-next): APIs may still change">
Levels L0 to L2 are implemented in `0.1.0-next.0` (models, `defineResource`, hooks, custom routes and UI overrides). Custom actions and L3 (eject) are **Planned**.
</Aside>

## The car analogy

| Level | Car | Strutvane | You write |
|---|---|---|---|
| **L0: Declare** | Autopilot. Tell it the destination. | Write the model and get everything. | Field names and types |
| **L1: Configure** | Adjust the settings: seat, mirrors, driving mode | Change options: labels, page size, columns | A few options |
| **L2: Override** | Swap one part: better tyres, new radio | Replace one action, hook, column or page | Just that one piece |
| **L3: Eject** | Build your own custom part from the blueprints | Copy the full source code and change anything | Whatever you need |

Most of your app stays at L0 and L1. You drop to L2 or L3 only where your business is special.

## L0: Declare

```ts title="app/models/invoice.model.ts"
export const Invoice = defineModel('Invoice', {
  number: field.string().unique(),
  amount: field.decimal(12, 2),
  status: field.enum(['draft', 'sent', 'paid']).default('draft'),
})
```

You get the full API, permissions, docs and screens.

## L1: Configure

Same engine, different settings:

```ts title="app/resources/invoice.resource.ts"
import { defineResource } from '@strutvane/framework'
import { Invoice } from '../models/invoice.model.ts'

export default defineResource(Invoice, {
  includes: ['customer'],                      // clients may ask for ?include=customer
  pageSize: { default: 50, max: 100 },
  routes: { delete: false },                   // switch off one endpoint
  ui: { icon: 'receipt', group: 'Billing', listColumns: ['number', 'customer', 'amount', 'status'] },
})
```

## L2: Override

Add your business rules at exactly the right moment, using **hooks**:

```ts title="app/resources/invoice.resource.ts"
export default defineResource(Invoice, {
  hooks: {
    // runs before an invoice is saved for the first time; return the changed input
    beforeCreate: async (input, { tenantId }) => ({
      ...input,
      number: await nextInvoiceNumber(tenantId),
    }),
    // runs after an update, with the record before and after
    afterUpdate: async (record, previous) => {
      if (record.status === 'sent' && previous.status !== 'sent') await notifyCustomer(record)
    },
  },
})
```

There are hooks before and after list, show, create, update, delete and restore, plus `transformResponse` to shape each record on its way out. Throw a Strutvane error (like `ValidationError`) to stop the request with a friendly message.

On the screen side, swap one column or input with a UI **override** (see [The UI](../the-ui/)). Everything else stays automatic.

<Aside type="note" title="Planned">
**Custom actions**, like "approve", with their own endpoint, button, permission and docs, come in a later release. Until then, use a [custom route](../auto-api/#your-own-endpoints).
</Aside>

## L3: Eject

For a truly custom screen or endpoint, take full ownership (**Planned**):

```bash
pnpm sv eject api Invoice            # full CRUD code → app/http/controllers/invoice.controller.ts
pnpm sv eject ui Invoice --page form # full form code → web/pages/invoices/form.tsx
```

It's ordinary code in your project now. Change anything you like.

<Aside type="tip" title="What about updates after ejecting?">
This part already works for generated files. When Strutvane improves its templates, `pnpm sv upgrade` offers the improvements for your ejected files using a **three-way merge**, like Git does. It compares the original template, the new template and your edited file. Your changes are never silently overwritten. If something conflicts, you see exactly where.
</Aside>

## Why this matters

Many tools force a choice. Either they generate lots of code you must maintain forever, or they run a "black box" you can't change. Strutvane gives you both ends, plus everything in between, **one piece at a time**.
