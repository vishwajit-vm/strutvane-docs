## Where we are now

<Badge text="Phase 0: Foundations, complete · Phase 1 next" variant="success" size="large" />

- ✅ The complete design (the "blueprint") is written and public
- ✅ Package names are reserved on npm under `@strutvane`
- ✅ One GitHub repository per package is set up
- ✅ Shared tooling and automated checks run on Linux, Windows and macOS
- ✅ The first draft of the shared definitions (contracts) is built and tested
- ✅ Nine experiments ("spikes", 419 tests) proved the riskiest ideas work before any real code: migrations, permission rules to SQL, tenant isolation, the typed registry, the API client, safe upgrades, sign-in, the generated UI and logging. They also found and fixed real security problems early.
- 🔨 Next: Phase 1, the core, the CLI, the framework and logging

<Aside type="note">
Timings assume a small core team and may change. Each phase only ends when its quality checks pass. We'd rather be late than broken.
</Aside>

## The phases

<Steps>

1. **Phase 0: Foundations** (weeks 0–4)

   Names reserved, repositories, shared tooling and automated checks, and experiments ("spikes") for the hardest problems: turning models into migrations, turning permission rules into database queries, and database-level tenant isolation.

2. **Phase 1: Core, CLI and framework → version 0.1** (months 1–3)

   You'll be able to create a project, write models, run migrations, and get a working, documented API. **This is the first version you can try.**

3. **Phase 2: Auth → version 0.2** (months 3–5)

   Sign-in, roles, permissions, policies, multi-tenancy and the audit log.

4. **Phase 3: UI → version 0.3** (months 5–7)

   Automatic screens, sign-in pages and theming. Full-stack apps in one command.

5. **Phase 4: Enterprise features → version 0.9 beta** (months 7–9)

   MySQL and Azure databases, single sign-on, background jobs, caching, monitoring and API versioning.

6. **Phase 5: Hardening → version 1.0** (months 9–12)

   An independent security audit, complete docs and example apps, and a long-term support promise. **Ready for production.**

7. **Phase 6: More packages** (year 2)

   Notifications, file uploads, payments and billing, reports, analytics, search and real-time updates.

</Steps>
